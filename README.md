# CareerMate AI 🚀

**An AI-Powered Career Guidance Platform**

CareerMate AI is a Python-based application designed to help students explore career opportunities, improve their skills, prepare for interviews and plan their professional journey.

## Features
- User Registration and Login
- AI Career Guidance Chatbot
- Career Recommendations
- Skill Assessment
- Interview Preparation
- Internship Information
- Resume Assistance
- Personalized Career Roadmap

## Technologies Used
- Python
- Streamlit
- SQLite
- Pandas
- Machine Learning

## Installation

1. Clone the repository:
   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder:
   ```bash
   cd CareerMate-AI
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:
   ```bash
   streamlit run app.py
   ```
